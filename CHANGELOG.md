# Changelog

All notable changes to Spatial Hardware Inspector are documented here.

## [1.0.0] - 2026-08-22

### Added

- Universal runtime loading for local GLB files and CORS-enabled GLB/GLTF URLs.
- Optional engineering manifest with exact millimetre dimensions and per-part status.
- Exploded, assembled, focused, full-view, orbit, pan, zoom, selection, and dimension modes.
- Two-hand target lock, focus, and return gestures.
- Multi-camera selection, mode recommendations, and exposed browser hardware controls.
- MediaPipe recognition in a dedicated worker with fresh-frame scheduling and CPU/GPU calibration.
- Adaptive exploded-view lighting and live camera-to-result latency reporting.
- Local runtime assets, stable Windows launcher, automated package checks, and production build.
